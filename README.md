# KreatifIn

**KreatifIn** adalah solusi digital yang dirancang untuk menjembatani kebutuhan kolaborasi di ekosistem kreatif. Platform ini mengutamakan estetika minimalis, keamanan data, dan kecepatan akses.

<p align="center">
  <img src="public/preview.png" alt="KreatifIn Preview" width="100%" />
</p>

## Fitur Utama

- **Unified Authentication:** Sistem login tunggal menggunakan Laravel Breeze yang aman.
- **Responsive Interface:** Kompatibilitas penuh di berbagai ukuran layar perangkat.
- **Error Management:** Penanganan *exception* halaman 404 & 500 kustom.
- **Secure Middleware:** Proteksi rute halaman untuk memastikan akses yang legal.
